# Low Budget AI — YouTube Topic Research

Goal: topics where search demand exists but existing YouTube coverage is weak. **Gaps, not trends.** Assessed via web search of YouTube + the surrounding blog/forum ecosystem.

## Saturated — do NOT make these (coverage already strong)
- **Cheap AI agent on a VPS** — multiple videos ("This $10 VPS Runs My AI Agents 24/7", "Put your AI Agents on a VPS", "Build your Own AI Agent Team").
- **Cheapest LLM for agents / tool calling** — very crowded. Note: the digest repeatedly flagged "cheapest models that actually handle tool calls" as episode material — it is now saturated; skip it.
- **AI agent sandboxing / blast radius** — multiple videos.
- **Prompt caching to cut agent cost** — covered, plus heavy blog coverage.
- **AI receptionist for small business** — crowded.

## Gap 1 (strongest): Model routing / LLM gateways — the honest cost comparison
- **Demand**: high and on-brand — cost-cutting is the channel's core theme. Active signals: Reddit "24x cheaper by using open router", Facebook "low budget openrouter", OpenRouter's own "lowest-cost inference" tutorial.
- **Existing coverage**: blog content is rich, but YouTube coverage is thin and fragmented — ~4 videos, almost all "OpenRouter vs LiteLLM" or vendor promo. Nobody owns the angle: **the free open-source routers beat the paid platforms on raw cost, and one paid platform charges a fee just to load your account** (hidden fees, markup, TOS gray areas).
- **Suggested angle**: "Which model router is actually cheapest? (OpenRouter vs LiteLLM vs OmniRoute vs 9Router — hidden fees included)".
- Evidence: https://youtube.com/watch?v=-xdPoj3iDmk , https://openrouter.ai/blog/tutorials/how-to-get-the-lowest-cost-llm-inference-on-openrouter/

## Gap 2 (frontier, lower demand): AI agents on real mobile devices / cloud phones
- **Demand**: emerging, more speculative. Signals: dev.to "Turn Old Android Phones into AI Agents", Reddit "Built Android AI agent that operates all apps", Multilogin's open-source cloud-phone agent.
- **Existing coverage**: very thin on YouTube — mostly dev.to/Reddit/blog.
- **Why it's a gap**: a genuinely "nobody's covering this" topic, and on-brand (a cheap way to run agents on real devices). But demand is less proven — treat as a second-order bet.
- Evidence: https://dev.to/priya_negi_9ffd29931ea408/how-to-turn-old-android-phones-into-ai-agents-complete-guide-c6e

## Recommendation
Lead with **Gap 1 (model routing / LLM gateways)** — strongest demand-to-coverage ratio and a differentiated, on-brand angle (hidden fees, free open-source routers beating paid platforms). Gap 2 (mobile/cloud-phone agents) is a worthwhile frontier bet if the channel wants a "first to own it" topic.

## Method note
Assessed via web search (YouTube results + surrounding blog/forum ecosystem). No YouTube API view-count data available; demand inferred from search-result density and community activity.
